
Interactive Python Quiz Game

A simple, interactive terminal-based multiple-choice quiz game written in Python. This project tests general Python programming knowledge, tracks scores, and provides instant feedback and final performance summaries.

🚀 Features

Multiple Choice Questions: Presents questions with four clear options (A, B, C, D).

Input Validation: Prevents crashes and retries if invalid choices are entered.

Instant Feedback: Shows whether your answer is correct or incorrect immediately.

Score Calculation: Tracks score and displays a percentage rating at the end.

🛠️ Prerequisites

Python 3.6 or higher installed on your system.

To check if Python is installed, run:

python --version


💻 How to Run

Clone or Download this repository.

Save the game script as quiz.py.

Open your terminal or command prompt in the project folder.

Run the script:

python quiz.py
